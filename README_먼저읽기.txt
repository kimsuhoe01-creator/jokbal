족발신선생 박닌점 실시간 주문 업데이트

추가된 기능
- 고객 장바구니: 주문 완료 · 직원에게 전송 버튼
- 전송 성공 후 고객 장바구니 자동 초기화
- 고객 화면: 직원 확인 대기 / 주문 접수 / POS 입력 / 완료 상태 실시간 표시
- 카운터 전용 화면: counter.html
- 신규 주문 소리·진동·화면 알림
- 신규 / 접수 / POS 입력 / 완료 주문 현황
- 직원 로그인 및 주문 상태 변경
- 고객 태블릿별 테이블·태블릿 번호 저장
- 고객용/카운터용 PWA 가로모드

중요
서로 다른 태블릿끼리 주문을 주고받으려면 Firebase 연결이 반드시 필요합니다.
FIREBASE_SETUP.md 순서대로 설정한 뒤 js/firebase-config.js에 Firebase 설정값을 넣으세요.
직원 계정 비밀번호는 코드나 GitHub에 절대 넣지 않습니다.

실행 주소
- 고객 메뉴: 기존 주소/index.html
- 카운터: 기존 주소/counter.html

카운터 화면은 실행 후 '알림 켜기'를 한 번 눌러야 소리 알림이 작동합니다.
